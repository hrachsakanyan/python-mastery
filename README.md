# 🐍 Python Mastery — Python Course in Armenian

An interactive, in-depth Python course **taught in Armenian** 🇦🇲 — from the fundamentals through Object-Oriented Programming (OOP). The whole course lives in a single page, and you can **write and run Python code right in your browser** (Python runs inside the page — no installation needed).

> **Note:** All lessons and explanations are written in **Armenian (հայերեն)**. Code, keywords, and technical terms are kept in English.

### 🌐 [👉 Open the course](https://hrachsakanyan.github.io/python-mastery/)

`https://hrachsakanyan.github.io/python-mastery/`

---

## 📚 What's covered 

27 topics across two phases — from the fundamentals to Object-Oriented Programming.

### Phase 1 — Fundamentals (19 topics)
Installing Python & tooling · Variables and Data Types · Operators (arithmetic, logical) · Modules (`math`, `random`, `datetime`…) · Conditions & Loops · Tuple, List, Dictionary, Set · Virtual Environments (venv) & pip · Git & GitHub · Functions (`*args`, `**kwargs`, recursion) · Error handling (try/except) · File handling (text, CSV, JSON) · Algorithms (Linear/Binary Search, Bubble Sort)

### Phase 2 — OOP (8 topics)
Intro to Object-Oriented Programming · Classes in depth · Constructors & Destructor (`__init__`, `__new__`, `__del__`) · Inheritance (`super()`, MRO, Mixin, ABC) · Polymorphism & Magic Methods · Encapsulation & Abstraction · Getters / Setters · Decorators

## ✨ Features

- 💻 **Live code** — write and run Python right on the page (Pyodide / WebAssembly)
- 🌗 **Dark / Light** mode
- 🎨 Syntax highlighting and clean formatting
- 📊 Mermaid diagrams
- 📈 Progress bar and handy sidebar navigation
- 📱 Works on both desktop and mobile

---

## 🚀 How to use

No installation required — just open the [link](https://hrachsakanyan.github.io/python-mastery/) in your browser. (On first load, the Python environment takes a few seconds to download; after that everything runs fast.)

## 🛠 Built with

A single self-contained `index.html` file, no build step — [Pyodide](https://pyodide.org) · [marked.js](https://marked.js.org) · [highlight.js](https://highlightjs.org) · [Mermaid](https://mermaid.js.org)
